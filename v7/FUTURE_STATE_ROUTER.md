# 自训练未来状态编码器与案例预测路由

本实验用一个自行训练的多变量编码器预测后续状态，再匹配旧案例真正发生过的未来状态。它不使用Moirai隐藏向量作为检索编码，也不将当前查询真实未来输入检索。Moirai仍负责原始基础预测，基础适配器、未来状态编码器与采用策略均在部署前固定。

## 未来状态如何表示

每个变量的未来96点划分为6个16点块。每块均值减去该变量历史最后16点的均值，再除以历史波动尺度，构成该变量的6维后续变化。尺度下限为初始历史库标准差的十分之一。联合C个变量得到6C维未来状态。

训练时，真实训练未来用于构造这个监督目标。已完整观测的旧案例未来也用同样的规则构造原型。推理时只有当前96点多变量历史进入编码器，输出的是预测的未来状态。weather与ETT使用同步的全变量历史；大量变量的数据集为每个目标变量选取自身加最多7个相关变量，相关性只由初始历史库前缀决定。

编码器输入保留历史6块相对变化、原始水平相对初始库的偏移、波动尺度与初始尺度的比值、有效覆盖率、已知日内和年内周期。分组版本额外保留周内周期。它是一种多输出岭回归，直接学习历史到未来状态的映射，不是硬聚类，也不保证每个未来状态都可由历史判定。

岭惩罚只通过训练区间的两个清除192点重叠间隔的向前折选择。未来状态各维度的可靠性也只由这些训练折的预测误差决定：难预测的维度降权，较稳定的维度保留更多权重。同步查询先按开始时间去重，不能把同一窗口在不同目标变量下的重复引用当成独立训练案例。

## 原型如何参与重排

先保持原召回的100个形状候选。基础兼容先验仍为0.8未来兼容分数加0.2历史相似分数，再增加预测未来状态与候选已知真实未来状态的可靠性加权距离。距离系数从0、0.25、1、4中仅用训练区间的向前预测查询选择。保留5个案例以及原多样性惩罚。

每个候选的完整192点窗口必须在当前查询历史开始之前结束，并且在初始历史库范围内。这个规则同样适用于补充的早期训练查询，不能检索自身或任何与自身重叠的窗口。旧案例中若某个其他变量缺失，该变量对应的原型维度会被掩码，不会把填补值当作已知未来；目标变量的候选本身必须完整有效。

选出的5个案例仍提供原始96点实际后续。先对齐历史末段水平，再以当前与案例历史波动尺度之比调整幅度，比例限制在0.25到4。这种预测保留真实案例的细节路径；独立对照则只用相同编码器预测的6个未来块均值插值得到路径，没有检索信息。

## 两种预测信息如何融合

所有路径先与已经适配的无RAG基础预测比较，产生修正量，修正范围不超过Moirai90%与10%分位跨度的四分之一。候选专家包括编码器独立预测、案例预测，以及两者按预先列出的比例混合。

对每个目标变量，验证前两块用于选择专家与修正比例，要求MSE、MAE同时改善，并满足多数窗口改善与重采样收益下界；最后一块只能确认或拒绝已经选定的专家。最终预测可选择基础预测、编码器修正、案例修正或混合修正。路由选择不读取测试损失。基础适配专家若在最后验证块被拒绝，会回退基础模型并禁用依赖该基础专家的新增修正，不能在同一确认块上再次寻找替代。

必须报告同一编码器去掉检索的对照。增加一个新的可训练预测器本身就可能改善结果，只有案例分支在同等训练条件下继续贡献收益，才能认为检索有效。多专家筛选、区间约束与确认块不保证新时期不会退化，各个误差指标也可能出现不同方向。

## 补充收益学习对照

`complementary_rag.py`还保留另一条对照：先在训练区间进行嵌套向前拟合，得到基础适配器没有拟合过的查询预测，再学习哪个旧案例能够修正剩余误差。外层查询的标签不能影响其基础教师模型或内层惩罚选择。候选收益目标是实际后续创新与剩余误差的协方差，并包含修正能量代价。独立查询过少时，不强行搜索收益模型，而使用零增量专家。

这条对照与联合未来状态编码是不同的实验，不能把不同测试集上的最佳结果拼成一个事后系统。

## 文件与验证

- `future_state_encoder.py`：自身训练的联合未来状态表示与缺失原型掩码。
- `benchmark_future_state_rag.py`：同步少量变量实验及编码器独立预测对照。
- `benchmark_group_future_state.py`：大量变量的数据分组与共享状态监督。
- `query_future_state_rag.py`：复用模型的历史输入预测接口，同时支持联合和分组版本。
- `evaluate_joint_future.py`：先冻结检查点和引用，再测试不与已有测试窗口重叠的剩余窗口。
- `verify_future_router.py`：重新拟合全部编码器、重算选择与路由、核对预测和原始误差、审核候选及新窗口时间边界。
- `verify_future_query.py`：实际GPU历史输入预测与配对缓存核对。

测试包含外层未来标签扰动、当前与其他变量未来数值扰动、全局变量编号与分组局部编号对应，以及历史相同而未来相反时的条件收益选择。已被查看的时期即使换成不重叠窗口，也不等同于新的年份或数据集盲测。模型权重、预测、指标和报告均只写入本地忽略目录，仓库只发布实现与机制说明。

```powershell
python -m v7.benchmark_future_state_rag --checkpoint-root <base-run-parent> --complementary-root <complementary-parent> --output <new-run-parent> --datasets weather
python -m v7.verify_future_router --root <new-run-parent> --rebuild-root <new-audit-parent> --datasets weather
python -m v7.verify_future_query --root <new-run-parent> --datasets weather
```
