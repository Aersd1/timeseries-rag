# 扩展前推覆盖：树模型与原始时序选择器

本实验保持96→96、100候选、重排评分0.8未来/0.2历史和5+5案例结构。
新增历史前推预测用于训练选择器，比较统计特征小网络、直方图梯度提升树，
以及直接读取完整96点序列的时序选择器。默认使用校准区间确定的组合策略；
拒绝修正时精确输出冻结Moirai。数据、预测、权重和报告不发布。

## 前推数据

在TRAIN约35%、60%、80%处设置三个截止点。各截止点从头拟合未来状态
检索编码器、通道分组、归一化和五组预测专家，再预测下一段。旧案例完整
192点必须在查询历史开始前观测完；预测专家的拟合标签必须结束于截止点，
前推查询历史从截止点之后开始。跨下一截止点的192点标签会被清除。

Moirai本身保持同一固定预训练版本，无需按前缀重训；它的缓存仅由96点
历史计算，32点历史回测由此前64点得到。历史案例的值始终是旧真实未来
减去同一个冻结Moirai的96点中位数预测。缓存、物理数据和模型都校验哈希。

前推查询以96为步长，每个数据集最多128个均匀分布的不同时间起点。
每个变量、每个截止点的预测专家最多使用64个均匀分布的训练起点，固定
种子13、16轮、同一32宽网络和相同损失，不使用VAL早停。
最后在完整TRAIN上重训同样五个专家，用于VAL和TEST。

五个专家分别读取：仅查询、查询加案例历史、真实案例残差、完全错配残差、
状态匹配随机案例。它们独立训练，结构和预算相同。预测专家使用一个固定
种子；选择器使用三个种子。不能把三个选择器种子声称为三次完整上游实验。

## 5+5与旧方案的关系

第一路的前缀未来状态编码器最多使用四个同步通道，邻居仅由截止点之前
的相关性确定；同伴当前历史缺失时采用已观测缺失掩码。它使用原有
future_state_encoder的历史特征与未来状态目标，固定岭惩罚10。
先按0.8状态距离/0.2历史距离召回100，再以Moirai未来分数0.8、历史分数
0.2重排选五个。第二路仍按原始数值历史选出五个不同案例，内部间距至少192。

库固定为数据集原始初始记忆区间，并受当前拟合截止点限制。取消旧VAL按变量
选择更长记忆区间的决定，避免把该决定带回更早的训练时期。随机案例同样只
根据已观测历史状态匹配，排除真实十案例相同起点；允许与真实案例部分重叠。
全部错配组在各五案例组内保证没有残差留在自己的历史键上，保持残差集合。
随机第一组仅保证起点去重，第二组另保证192点间距；其集合多样性与真实
组不保证完全一致，不能把真实与随机的差值全归因于检索打分。

因此本轮不是旧全TRAIN索引的字节级复用，案例也不会逐条相同。旧方案与本轮
的差值不能只归因于选择器或数据量。所有本轮的模型、稀疏/广覆盖对照均使用
同一批新前推候选和同一批最终测试案例，才用于判断覆盖和模型的作用。

## 选择器比较

| 模型 | 输入 | 固定训练设置 |
|---|---|---|
| summary_mlp | 52维当前状态、候选修正与历史能力特征 | 两层32宽GELU，20轮 |
| hist_gbdt | 同样52维特征 | 100轮直方图提升，15叶，最小叶32，学习率0.05 |
| raw_sequence | 上述信息加完整96点当前序列、九分位预测、候选路径、十案例历史与残差 | 两层32宽、四头时序编码器，案例交叉注意力，20轮 |

三种模型都回归候选相对直接Moirai的收益与负收益幅度。标签为分时段MSE
差，按第一个前缀的标准差归一化。固定种子13/41/73；树模型按同步起点做
Poisson时间块加权以形成三个成员，神经网络使用三个初始化种子。
各模型家族内五组输入对照同预算；不同家族不宣称参数量或计算量完全相同。

具体地，对每个8点预测时段，以冻结Moirai预测为b、融合专家候选为c，训练
收益标签 u=(MSE(b,y)-MSE(c,y))/s² 与风险标签 max(-u,0)，s来自首前缀。
两个标签再除以拟合队列收益的均方根。三个选择器输出收益均值、风险均值
和收益分歧，分数为“平均收益−风险系数×平均风险−不确定性系数×分歧”。
只有分数超过验证阈值，才输出 b+strength×(c-b)，否则该8点保持b。
候选由已经训练好的残差融合专家给出；选择器判断是否采用该候选，不直接
把预测标签作为检索输入，也不把理论上“知道未来再选择”的成绩用于部署。

两种拟合数据分别为全部前推记录forward_full，以及仅最后四个同步起点
sparse_last4。后者仍读取同一已观测历史能力库，只减少拟合标签，从而避免
改变输入可用信息。这个对照同时改变了样本数和覆盖时间，不能把差异解释成
单独增加时间跨度的因果效应。所有输入归一化只在各自拟合队列上计算。
两队列神经网络均训练20轮，因此全量队列的优化更新次数也更多；这不是
等总计算量的覆盖实验。家族内五组输入对照在同一队列上才具有相同预算。

原始时序模型按当前历史和固定首前缀尺度归一化并限幅后，保留全部96个
采样点、对应预测时段的案例残差和状态信息；不是未处理的物理原值。
仅查询对照用当前已观测回测误差激活同一记忆分支，不提供旧真实未来；
仅案例历史预测分支同样不直接读取旧真实未来，但复用同一批未来感知检索
的案例。它隔离显式残差值的额外作用，不是彻底移除旧未来对案例选择的影响。
历史能力特征仅使用在当前历史开始
之前已经完整发生的96→96预测，不能用拟合内预测误差冒充前推收益。

## 校准、确认与默认输出

TRAIN之外的VAL用96步长生成更密集查询，按同步起点分成四段，清除每段
边界跨越的192点标签。前两段选择风险系数0/0.5、不确定性系数0/1、
分数阈值0/0.05/0.1/0.25/0.5/1，以及修正强度0.1/0.25/0.5/1。
每段均要求原始MSE、归一化MSE、MAE不退化。

后两段只确认或拒绝。每个模型家族单独保存一个输出；另在前两段从三个
家族及静态强度策略中选一个组合策略，后两段只确认这个已选策略。
若它被拒绝，回退Moirai，不用确认结果再挑另一个家族。

主输出固定为forward_full__real__portfolio。查询、案例历史、错配、随机
也采用完全相同的家族搜索预算，不能只拿真实组的最佳家族对照查询组单一
模型。源代码内部train_nmse在本实验使用固定首前缀标准差，报告称为
anchor NMSE，不冒称完整TRAIN标准差。所有候选/参数在TEST之前冻结。

## TEST与稳定性

保留原先完全相同的稀疏TEST查询作legacy对照，另用96步长覆盖完整TEST。
dense为主测试口径，legacy单独报告；两个集合不混合计算主指标。
直接Moirai在legacy查询上的预测和真值必须与旧实验逐值一致。

稳定性预先定义为：相对Moirai原始MSE改善的按周时间块重采样95%区间下界
为正，且四个连续TEST时间段的改善均为正。按同一时间块同时抽取所有变量，
不将变量或预测点当成独立时间样本。不按TEST删除退化变量或更换主输出。
RAG的额外价值还要比较同队列、同家族搜索预算的仅查询与仅历史对照，
并进一步比较状态随机和全错配对照。回退导致持平不构成检索收益。
真实方案未采用修正却胜过较差的查询网络，也不能解释成历史产生了收益。

这些TEST时期已经在开发中多轮查看；扩大查询覆盖也不等于新盲测。
本轮新管线对前推标签按前缀拟合，但不能据此宣称消除了此前开发选型偏差。
固定初始案例库可能覆盖不了之后的状态；无收益不能外推为所有RAG都无效。
Illness长度不足共同协议，不伪造同条件分数。

## 运行

```
pip install -r v7/requirements-forward-selectors.txt
python -m v7.dense_forward --source <unified-root> --output <new-root> --datasets <names> --device cuda
python -m v7.forward_experts --source <unified-root> --output <new-root> --datasets <names> --device cuda
python -m v7.benchmark_forward_selectors --source <unified-root> --output <new-root> --datasets <names> --device cuda
python -m v7.benchmark_forward_selectors --source <unified-root> --output <new-root> --datasets <names> --device cuda --test
python -m v7.verify_forward_selectors --root <new-root> --datasets <names> --device cpu
python -m v7.verify_forward_selectors --root <new-root> --datasets <names> --device cuda --skip-prefixes
python -m v7.verify_forward_selectors --root <new-root> --datasets <names> --device cuda --deploy-only
python -m v7.verify_forward_selectors --root <new-root> --datasets <names> --device cuda --intervene-only
```

已完成阶段与策略不可覆盖；中断可从已经验证的缓存/模型继续。
TEST的Moirai缓存与TRAIN/VAL缓存分开，不能追加改变拟合数据的哈希。
部署类为query_forward_selectors.ForwardSelectorPredictor。它只接受当前历史，
内部ObservedStore限制所有读取不超过当前历史末端。返回逐时段采用标志，
拒绝时保持Moirai逐值一致。CPU/GPU数值重放、旧案例物理边界与实际检索
应核验后再报告结果。报告、数据和权重始终留在本地忽略目录。

部署核验重新执行真实检索，检查案例起点、候选与冻结输出，并将存储物理
截断于当前历史末端后再次预测。接口返回case_inputs与case_branch_adopted，
它们表示提供了多少案例及是否应用分支，不能解释成每条案例已经证实有用。

设备核验独立保存原生分数误差、采用决定差异与预测差异。GPU重放分数
使用rtol/atol=5e-5。CPU时序注意力核允许有界舍入放大：以1+绝对参考
分数缩放后，RMS小于1e-4、99.9%分位小于1e-3、最大值小于5e-3；
不得据此声称CPU/GPU原生采用决定逐值相同。所有精确路由、回退和指标
重放都基于已冻结GPU分数，另保留CPU原生决定变化供核查。
若CPU数值超过这些界限，应保留失败并明确未通过，不为获得通过而放宽
界限；文件完整性、时间隔离和CUDA原生重放应独立核验。CPU检查在首次
失败处停止，因此不能据此前几组成功就声称其余CPU输出已经通过。

另可执行同权重参考干预：保留最终真实专家的全部权重、原始采用位置和
全局修正强度，仅将旧残差置零、在各五案例内部完全错配，或换成状态匹配
随机案例。原始候选和固定采用位置下的输出分别比较。它用于补充独立重训
对照，检查预测是否实际依赖参考内容，不会改变主策略、阈值或测试输出。
这是事后诊断：置零可能产生输入分布偏移，原采用位置仍由真实参考确定，
因此不能单凭干预损失差宣称完整因果效应或部署收益。

## 后续改进设计（尚未实现或验证）

优先把不读取案例的适配预测B与检索增量分开训练和评价。先用前推数据训练
并确认B能否优于直接Moirai，再冻结B；检索分支只能增加修正delta。选择器的
收益标签应改成MSE(B,y)-MSE(B+delta,y)，而不是只判断融合候选是否胜过
原始Moirai。这样能区分适配网络带来的提升和检索额外贡献。

在训练中加入空参考，使拒绝参考成为训练分布内的行为；同一分支可用
F(x,R)-F(x,empty)定义增量，在真正无参考时严格为零。需要分别比较完全
空案例、只去掉案例未来残差、完全错配和状态匹配随机案例，不能用只清零
未来残差代替彻底移除所有历史信息。这个结构约束本身不保证检索有效，仍须
独立前推验证。基线与检索分支不能共同改变后再把全部差值记为检索收益。

若e=y-B、输出为B+alpha*delta，则平方误差下降为
2*alpha*E[e*delta]-alpha^2*E[delta^2]。因此应检验修正与基线剩余误差是否
同向，不能用历史或预测形状相似度替代真实增量收益。参考数仍保持5+5，
先单独验证上述目标变化，再考虑替换检索编码器或扩大模型。

固定初始案例库与因果滚动案例库应另做对照。滚动加入的案例必须已完整
发生，并继续满足旧192点案例结束不晚于当前查询历史开始；所有比较方法
应有相同的信息可用边界。不能把较宽松的参考时间边界带来的提升混作检索
打分改善。如果改变残差参照模型，也须重新生成可前推核查的旧预测误差，
不能使用拟合内残差冒充泛化误差。

相关方向可参考预印本[FreshCast](https://arxiv.org/abs/2610.07834)：其研究
滚动记忆及时性、参考修正与冻结预测误差的互补关系，以及验证集上的组合
权重校准。论文结果不等于本实现已取得同样收益，也不证明固定初始案例库
就是本轮退化的唯一原因。任何下一版都需要新的时间留出段与同预算消融，
不能直接把本轮TEST上较好的干预输出当成新部署策略。
