# 快速区分长期上下文与案例选择的收益

本实验不训练网络、不调融合权重、不替换当前固定5+5入口。
先写明比较协议，再固定每个数据集已有TEST的首、中、末三个查询历史起点，
保留所有变量。在所有方法中使用相同、完整且有限的2016点历史/96点目标队列。
如果2016点历史跨越缺失区间，该条查询在所有方法中一起排除，不填补缺失值，
也不改选另外一个时间点。三起点只是快速筛查，不能代表全测试时期。

## 比较项

| 方法 | 新增预测网络 | Moirai本次实际输入 |
|---|---|---|
| moirai_96 | 无 | 当前原始96点；复用固定预测并做真实GPU抽查 |
| moirai_512 | 无 | 截至当前预测边界的连续512点 |
| moirai_2016 | 无 | 截至当前预测边界的连续2016点 |
| packed_real | 无 | 原5+5的十个完整96历史/96旧未来案例，再接当前96点 |
| packed_random | 无 | 已准备的历史状态匹配随机十案例，再接当前96点 |
| packed_periodic | 无 | 同冻结库内最接近日内相位的十案例，再接当前96点 |
| packed_recent | 无 | 同冻结库末端最近的十案例，再接当前96点 |
| packed_univariate | 无 | 当前变量原始历史MSE选五个、标准化历史形状MSE另选五个，再接当前96点 |
| restored_5plus5 | 复用旧冻结模块 | 原版预测，重新在本轮相同队列评分 |

所有新增方法使用同一个固定版本的Moirai2，预测未来96点。
不根据本轮TEST选择最佳历史长度、案例类型或部署分支。

## 案例与对齐

所有旧完整192点案例必须在查询历史开始前结束，且不超过原5+5已冻结的库边界。
近期案例是这个冻结库的末端案例，不是滚动加入VAL或TEST真值后的近期案例。
周期、近期案例内部间隔至少192点。单变量双路各五案例内部也至少间隔192点，
两组去重但不宣称组间完全不重叠。原5+5和匹配随机案例沿用各自原选择规则。

对当前历史x、旧历史p，斜率为
`a = std(x)*std(p) / (std(p)^2 + (std(x)/5)^2)`，
截距为`b = mean(x)-a*mean(p)`。同一个a、b同时变换旧历史和旧未来。
对齐只拟合历史，不使用当前真实未来，也不使用旧未来拟合缩放参数。

十个对齐后192点案例按实际旧起点排序，拼接为1920点，再追加当前原始96点。
Moirai直接对这个2016点序列预测，不再增加外部残差融合。
这只是朴素的案例拼接对照；模型没有特殊案例分隔符、时间间隔标记或专门的
示例训练。因此它失败不能证明所有上下文案例机制均无效。

## 公平性边界

连续2016与案例2016具有相同输入数值数量和相同基础模型接口，
不意味着其总信息范围、检索耗时、离线训练量或整个流水线计算完全相同。
连续长历史允许读取当前已经观测到的较近VAL/TEST历史；案例库保持旧冻结范围。
这是真实可用信息的比较，但不能将全部差值仅归因于信息压缩效率。

原5+5的上游选择器可能读取相关变量历史，旧预测也含已训练的适配模块。
packed_univariate只读取目标变量历史；原版分数不能当成纯单变量、无训练的检索收益。
所有GPU耗时是本次批量推理的计时，未优化、未扣除首次调用开销，不当作生产延迟。
96点及原版预测来自固定缓存，未对它们报告不公平的零推理耗时。

## 运行

```powershell
.venv-moirai-gpu/Scripts/python.exe -m v7.benchmark_memory_access --output v7/runs/memory_access_new --batch-size 32
.venv-moirai/Scripts/python.exe -m unittest v7.tests.test_memory_access -q
```

初步结果后另加`memory_shuffle`事后诊断，保留原比较结果。对已经对齐的十案例，
仅将未来半段循环错配一位，全部旧历史、当前历史和完整输入数值集合保持相同。
这可以排查仅因总体水平、幅度或额外数值集合带来的收益；它也会改变段落连续性，
所以退化不能独自证明模型识别了因果动力学。

```powershell
.venv-moirai-gpu/Scripts/python.exe -m v7.memory_shuffle --root v7/runs/memory_access_new
.venv-moirai/Scripts/python.exe -m v7.verify_memory_access --root v7/runs/memory_access_new
```

需要原始Store、原冻结案例缓存和本地Moirai权重。输出目录必须全新。
数据、预测、指标和报告留在本地；只发布源代码、单元测试和机制说明。
