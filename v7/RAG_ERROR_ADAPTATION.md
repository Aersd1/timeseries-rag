# RAG辅助预测：从案例误差迁移到直接学习预测误差

## 为什么补状态仍可能失败

归一化形状不是完整状态。水平、幅度、趋势和日内相位可以帮助匹配，
但不能创造历史库从未覆盖的状态，也不能保证相近状态的模型误差可迁移。
固定前25%历史库可能缺少后来的状态；复制一个完整96点误差轨迹，又
可能把旧事件中的随机波动也加到新预测中。仅估计案例收益的全局模型
还会受到变量异质性、时间漂移和重复相似候选的影响。

因此代码保留三种独立实验，避免把几种改动误认为同一个机制。
所有方案都先用冻结Moirai读取原始96点历史，预测96点未来；没有将
多个旧案例直接串入Moirai的历史上下文，也没有内部微调Moirai权重。

## 1. 在线误差案例与局部校准

`local_error_rag.py`保留原始前缀案例，并加入已经完成的旧查询。
旧查询的历史、后续、当时Moirai预测及误差，只有完整192点结束于
当前历史开始前才能使用。训练、验证和测试都执行这个限制。

仍召回100个、取5个案例，兼容先验仍为0.8预测未来兼容、0.2历史形状。
状态权重与误差参考数通过训练区间两次向前回测选择。
局部收益重排用少量相近且独立的已完成查询误差，估计当前基础模型
的误差方向，并按预期MSE收益排序；另一对照沿用兼容排序。

每次查询挑选最多12个相近、互不重叠的旧查询，以它们当时按因果顺序
生成的潜在修正和后来观测的真实误差，重新执行三块校准。前两块选
系数、第三块只确认或拒绝。不足9个独立查询则暂不采用修正。

在线协议允许先前验证/测试查询在完全观测后成为后续的案例和反馈。
它与固定前缀的离线协议不同；不能把这种额外信息的收益全部解释为
排序模型提升。当前真实未来和重叠案例始终排除。

## 2. 有界建议与保守专家选择

`safe_error_policy.py`将旧案例建议限制在Moirai当前10%–90%预测
分位数跨度的四分之一内，避免高幅度旧误差不受约束地覆盖新预测。
这是一个调整幅度限制，不代表该分位数区间已经通过概率校准。

每变量前两个验证块选择固定库兼容专家或在线专家，以及0.1、0.25、
0.5的外部系数。要求至少75%窗口改善，并且过去样本收益bootstrap
下界超过基础验证误差的1%。最后一个验证块只能确认此前选中的
专家，要求均值改善且至少75%窗口改善；否则回退直接Moirai。

这只是减少不稳定修正的风险，不能保证未来状态不变。
回退持平不能被描述为RAG有效。

## 3. 直接监督预测误差的小型适配器

`residual_adapter.py`不再间接预测某个候选的收益，而直接学习
`真实后续 − Moirai基础预测`。每个变量训练14维岭回归加截距，输入
在每个未来时间点由以下已知信息构成：

* 基础预测相对历史均值和最后观测值的偏离。
* 原始历史的均值、标准差、线性趋势，以及未来步长。
* 基础预测的分位数跨度。
* 未来已知日内相位的一、二阶正弦和余弦。
* 5个检索案例的加权误差、16点块平滑误差、平均误差。

未来时间戳可以预先知道，未来真实数值不能。RAG误差是已观测旧案例
在当时Moirai预测下的误差，不是当前查询真实误差。
候选仍来自固定前缀，排序权重仍为0.8/0.2，没有改变候选数量。

训练目标是归一化预测误差的平方损失。目标在训练样本1%/99%分位数
处截断，特征标准化也只用训练样本。岭惩罚在0.1、1、10、100中，通过
训练区间两次向前验证选择：拟合查询完整192点必须结束于后续查询
开始前。模型最终只用训练区间拟合，不用验证或测试标签训练系数。

输出经过上述幅度限制，再用三块保守验证选择采用比例。
最终预测是 `原始Moirai预测 + 被确认的有界误差建议`。
日内相位使用序列索引和采样间隔，未添加节假日或天气预报等外部信息。

另训练一个11维、不含三个RAG特征的适配器，采用相同训练选择和
验证规则。如果它一样好或更好，不能把改善归因于案例检索。

## 评估范围与解释

其他数据集沿用全变量的同一抽样缓存：每变量32个训练、12个验证、
12个非重叠测试窗口，原始案例前缀步长16。它不是遍历全部窗口或
官方基准切分；历史与预测长度都是96。

主NMSE按初始历史库各变量方差归一化，同时保存原始MSE、MAE及
逐变量采用情况。原始MSE在不同量纲变量混合时可能被大数值变量
主导，初始库NMSE也可能被历史方差很小而后来剧变的变量主导。
不能只挑好看的指标，也不能事后删除不利变量。

这些方案是在同一测试段上逐步探索出来的，阈值并非外部盲测得到。
训练与验证选择仍按时间隔离，但不能据此宣称未经开发选择影响的
独立泛化结论；需要新时间段和多随机种子确认。
机制与代码发布，数据、学习系数、缓存、报告和性能数值保留本地。

## 复现与核查

```powershell
python -m v7.benchmark_local_error_rag --output v7/runs/local_error_rag_96_20261013 --datasets weather electricity
python -m v7.benchmark_safe_error_policy --output v7/runs/safe_error_rag_96_20261013 --datasets weather electricity
python -m v7.benchmark_residual_adapter --output v7/runs/residual_adapter_96_20261013 --datasets weather electricity
python -m v7.verify_residual_adapter --root v7/runs/residual_adapter_96_20261013
python -m v7.verify_residual_query --root v7/runs/residual_adapter_96_20261013
python -m unittest v7.tests.test_residual_adapter v7.tests.test_local_error_rag v7.tests.test_state_recall v7.tests.test_benefit_rerank
```

输出目录必须是新的，以避免覆写旧实验。`query_residual_adapter.py`
只接收当前96点历史，读取经过哈希核对的历史误差与学习参数。
查询必须在验证结束之后，保证其策略用到的验证结果当时已可观测。
独立核查重新拟合所有训练模型与向前折、重建验证策略、复算所有
原始指标，并用真实Moirai历史接口回放已启用的单条查询。
