# 用历史内部检验约束检索适配

该实验保留原始96点历史进入冻结Moirai的96点预测。另用同一历史的前64点预测后32点：后32点已经被观测，因此这个小检验可以估计模型最近的偏高、偏低和误差变化，无需当前查询的真实未来。

`prepare_past_error.py`单独缓存这个检验，并绑定来源缓存和固定模型版本。`past_error_adapter.py`将检验误差、其他变量历史状态、周期状态和旧案例信息用于外部岭回归。模型本体没有被微调。

## 检索与重排

原召回仍取100个去趋势形状候选。原分数保持0.8未来兼容、0.2历史相似，在此之上增加候选已知模型误差与当前历史内部检验误差的距离。距离权重0、0.25、1只用两个清除重叠的训练向前折选择；不能通过测试损失选择。取5个案例时保留原多样性惩罚。

候选旧误差对应96到96预测；内部检验是64到32预测，两者的误差分布可能不同，因此匹配只是一种可检验的假设，不是未来正确性的证明。

5个案例提供两种信息：旧Moirai的真实预测误差，以及旧案例真实后续变化。后续变化相对于旧历史最后16点对齐水平，并按当前和旧历史波动幅度比缩放，比例限制在0.25到4；同时提供案例分歧，避免只输入平均路径。

同源相关变量只依据初始历史库前缀的相关性选择，最多4个。对查询只读取这些变量同一96点历史的均值、末值偏移、波动、趋势和有效覆盖率；缺失点用该变量初始历史库均值填补。不会读取它们的未来。

## 幅度、季节与训练覆盖

默认按初始历史库标准差学习误差。`--adaptive-scale`改用当前历史标准差与初始标准差十分之一的较大值：旧案例误差按旧历史幅度标准化，当前输出再乘当前历史幅度。额外保留当前与初始尺度的比值及对数。评估NMSE始终沿用初始历史库方差，不因训练单位变化而改变指标。

日内及周内相位属于已知周期信息。`--annual-calendar`额外加入365.2425日的年内相位、年内与日内周期交互、以及旧误差均值与年内相位交互。这些特征是季节代理，不是气象机理或日照时长的精确计算。

`augment_memory_training.py`可从初始历史库补充较早的训练查询。每个补充查询依然必须有100个完整旧案例，且所有旧192点案例在该查询历史开始之前结束。它不能检索自身或任何与自身重叠的区域。补充查询用于训练监督，其自身未来允许作为训练标签。验证、测试文件按原字节复制。默认补充32个早期查询，与原32个查询合并，使两个向前验证折仍落在初始历史库结束之后。

## 适配与采用策略

两种分支分别学习当前模型误差：有RAG分支包含案例特征，无RAG分支保留相同历史内部检验、相关变量、周期状态。不能只与直接Moirai比较就宣称RAG有用。

岭参数从0.1、1、10、100中仅依据训练向前折选择。输出修正限制为Moirai90%与10%分位跨度的四分之一。验证前两块选择采用系数0.1、0.25、0.5，要求多数窗口改善、重采样收益下界，以及MSE与MAE同时改善；最后一块只能确认或拒绝。没有证据则回退直接预测。区间限制和验证筛选不保证测试不会退化。

`--online`启用不同的信息访问协议：只允许在某旧查询的完整192点窗口结束之后，并且该窗口不与新查询历史重叠时，将该查询加入岭回归重拟合。参数及检索匹配权重仍由训练折固定。较早验证和测试窗口后来可以作为已观测反馈；必须与冻结头实验分开报告，不能把测试标签提前加入训练。无RAG分支使用相同反馈。

## 验证与复现

`verify_past_error_adapter.py`从训练缓存重建全部匹配权重、岭参数、模型、验证策略和指标，审核候选时间边界。`query_past_error_adapter.py`实现原始历史输入的预测接口；策略验证结果必须在查询开始前已观测，在线反馈只读取完整且非重叠的旧查询。`verify_past_error_query.py`在GPU重新预测并与配对缓存核对。

`evaluate_new_windows.py`在同一测试时期另外挑选不与原测试192点窗口重叠的新窗口。先保存引用和冻结检查点哈希，再执行预测，最后读取结果计算误差。不会依据新窗口结果重新选择模型。新窗口能检查窗口抽样的稳定性，但共享已查看的时期，不等同于新的年份或数据集盲测。所有指标、模型权重、预测、报告均只写到本地忽略目录。

例：先准备历史内部检验，再训练与审计。

```powershell
python -m v7.prepare_past_error --cache <raw-cache-parent> --output <probe-parent> --datasets weather
python -m v7.benchmark_past_error_adapter --cache <raw-cache-parent> --probes <probe-parent> --output <new-run-parent> --datasets weather
python -m v7.verify_past_error_adapter --root <new-run-parent>
python -m v7.verify_past_error_query --root <new-run-parent> --datasets weather
```

代码保留实验开关以复现失败的路线，不自动取各个测试数据集上的最佳结果作为最终系统。是否值得采用应由预先确定的验证协议和后续冻结评估决定。
