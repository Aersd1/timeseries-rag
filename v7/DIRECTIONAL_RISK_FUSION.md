# 在原固定 5+5 上判断检索修正是否有益

这是独立实验，当前入口仍为 [恢复后的固定 5+5](CURRENT_SCHEME.md)。创新范围是
本项目的融合设计，不声称是已获证实的新算法或论文首创。

## 判断修正方向，而不是只判断历史相似

固定原模型，令 N 为同一编码器的无检索预测，R 为恢复的固定增量迁移 5+5，
d = R - N。最终候选为 `N + alpha * d`，alpha 在 0 到 1 之间。

对平方误差，融合相对 N 的改善恰好为：

```
gain(alpha) = 2 * alpha * mean((y - N) * d) - alpha^2 * mean(d^2)
```

`mean(d^2)` 在预测时已经已知。真正需要学习的是：当前状态下，原检索修正 d
是否朝着有利的方向。模型估计单位修正方向上的残差投影，再由这个式子求连续
权重，不让新网络生成另一条预测曲线。正投影不等于整个 5+5 都值得采用；
修正太大时，最合适的权重仍可能远小于 1。

这与仅学习完整强度 R 相对 Moirai 的胜负不同。对照是同容量无检索 N，
因此更接近“检索是否有额外收益”；还必须单列 N 相对直接 Moirai 的收益，
避免把编码器适配收益当成检索收益。

## 实际读取哪些历史信息

输入使用当前原始 96 点历史及其水平、幅度、趋势、Moirai 分位区间、
N 与 Moirai 的差异。十个旧案例的 96 点历史和已观测未来均为实际输入：
每个五案例组的历史分段形状、离散程度、每案例完整 96 点历史差异、
原始水平差和幅度比，以及对应旧未来的分段均值和分歧。
没有当前查询真实未来输入。

独立重训 query_only 对照把新增判断器中的案例特征置零，保留相同特征维度。
它仍然给已有 R 分支分配权重，而 R 本身已经检索，不能把它称为完全无检索模型。
它检验的是判断器读取旧历史/旧未来是否有额外价值。

## 保留原专家，降低判断器容量

原编码器、案例库、100 候选、0.8/0.2 重排、十案例及原预测完全冻结。
只训练带固定正则项 10 的线性风险回归，五个固定种子按同步预测起点整组重采样。
多个变量处于同一起点时，整个起点总权重相同，避免把同步变量当成独立时间样本。

权重使用 `clip((投影均值 - lambda * 重采样标准差) / 修正能量, 0, 1)`。
重采样标准差是模型敏感性指标，尚不是有覆盖保证的置信区间。
lambda 仅在验证中从 0、0.5、1、2 选择。

## 时间划分与回退

原 VAL 按时间分三块，并清除跨块的完整 192 点查询区间。第一块用于训练
风险判断器，第二块选择一次融合策略，第三块只能确认或者拒绝。
候选包括直接 Moirai、原无检索 N、固定 alpha 和条件 alpha。
选择与确认都要求原始 MSE、MAE 和 TRAIN 尺度归一化 MSE 不差于原 R 与 Moirai，
并要求原始 MSE 比 R 有改善。确认失败保持原 R，不寻找第二个候选。

所有数据集的模型和策略先冻结，再统一打开本实验 TEST。真实检索案例仍要求
`case_start + 192 <= min(query_history_start, frozen_library_end)`。
核验固定预测与原保存结果一致，并用篡改当前目标的方式检查判断器输入不变。

这是复用已开发时期的探索。上游原检索策略还使用过这些 VAL，新增时间清除
不能使整条流水线变成全新的独立验证。判断器只见到的历史时间状态不足、
跨时期变化和基础预测偏差，仍可能使条件权重失败。不能承诺一定胜过原版。

## 运行

```powershell
.venv-moirai/Scripts/python.exe -m v7.benchmark_directional_risk --output v7/runs/directional_risk_trial
.venv-moirai/Scripts/python.exe -m unittest v7.tests.test_directional_risk -q
```

脚本使用全部七个已具备相同条件的数据集。目录必须全新，不覆盖冻结结果。
输入实际旧历史的特征、固定模型与当前无目标输入路径均可单独核查。
评测输出只留在本地，实验没有被切换到当前部署入口。
