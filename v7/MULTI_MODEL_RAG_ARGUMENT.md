# RAG有效性：命题、假设与可验证推论

这是实验协议的数学依据，基本恒等式和条件期望结论不作为原创理论声明。
所有平方范数取未来96点的平均，期望还对查询、记忆和训练随机性取平均。

## 命题1：有效性由误差对齐与校正代价共同决定

以同容量查询侧校准后的预测 `a_m=b_m+g_Q` 为参照，令
`e=Y-a_m`，`delta=(b_m+g_R)-a_m`。逐查询精确成立：

`L(Y,a_m)-L(Y,a_m+delta)=2<e,delta>-||delta||^2`。

证明：展开`||e-delta||^2`并相减。因而平均有效的充要条件是
`2 E<e,delta> > E||delta||^2`。历史相似只影响如何生成delta，不能直接
替代此条件。多数查询小幅获利、少数查询严重受损时，正收益概率超过1/2
也可能不满足条件；故门控应预测期望损失收益而不只是收益符号。

固定可用信息下，一个基准校正方向u乘强度alpha时，期望收益为
`2 alpha E<e,u> - alpha^2 E||u||^2`。若前一内积不正，任何正强度都不能
提高平均精度；若为正，过大的强度仍会退化。该结论直接给出方向干预与
同能量收缩控制，不需要声称所有情况只是检索质量或选择器容量问题。

## 命题2：不可预测的剩余误差不能靠历史案例消除

令I为预测时实际可用的信息，delta必须对I可测。如果
`E[e|I]=0`，则`E<e,delta>=E<E[e|I],delta>=0`，期望收益为
`-E||delta||^2<=0`。因此条件最优预测之后继续添加非零历史校正只会增加
平方风险。注意：实证中未找到收益，不等于已经验证了这个条件最优假设。

将有限算法限制暂时移除，若信息集合满足`I_Q`包含于`I_QR`，其最优残差
预测分别是`g_Q*=E[e_b|I_Q]`与`g_R*=E[e_b|I_QR]`，其中`e_b=Y-b_m`，
则最优风险差为：

`Risk(g_Q*)-Risk(g_R*)=E||g_R*-g_Q*||^2>=0`。

这是条件期望投影/全方差分解。若记忆固定且检索仅是完整查询H的确定
函数，条件在完整H上时两信息集合可能完全相同，信息论额外收益就是0。
实际有限模型仍可能因检索表示、额外计算、有限样本正则化而改善；因此
本研究将经验结论称为操作性增量，必须比较同容量查询校准、随机案例和
错配案例，不能仅凭误差下降宣称新增了信息。

## 命题3：历史可迁移性、模型能力和估计噪声产生交互

在给定当前历史/可观测状态下，记当前基础模型的平均可预测残差为g，
历史案例给出的估计为`g_hat`，均值mu、协方差Sigma。假设当前未来的不可
预测噪声与历史估计条件正交，则相对基础预测的期望收益是：

`||g||^2 - E||g-g_hat||^2`

`= ||g||^2 - ||g-mu||^2 - trace(Sigma)/96`。

由此产生四个不同的退化来源：

1. 基础模型已解释相关结构：`||g||^2`很小，新增校正机会有限。
2. 相似历史的转移关系不稳定：mu偏离g，迁移偏差大。
3. 状态未观测或条件后续多解：案例均值估计仍有高方差/噪声。
4. 案例大量重叠或有效样本少：加权平均方差不能按独立K例下降。

这个分解是有假设的局部论证。若历史库会受当前未来共同冲击、状态被
遗漏，条件正交可能不成立，不能用简单相关系数反推出真实因果参数。
真实数据检验采用完整时序隔离；合成试验分别干预残差信号、关系偏差和
噪声，来验证上述机制是否足以改变收益。真实因果归因还需要独立外部验证。

## 命题4：剩余误差依赖基础模型，而非数据集的固定属性

同一历史和目标下：`e_m=Y-b_m(H)`，不同模型满足
`e_m-e_n=b_n(H)-b_m(H)`。

因此同一历史案例对模型m和n的残差标签通常不同。将n的旧残差直接用于m
是未经校正的参考交换，不是“相同辅助信息”的公平比较。本轮主矩阵
全部使用本模型、同512历史下的旧案例残差，且旧案例未用于本地监督模型
训练。

源模型交换的一个严格实现检查是：
`e_n + (b_n-b_m) = e_m`。

若把另一模型旧残差按右式精确转换，必须与本模型旧残差逐项一致；否则
说明实现/归一化有问题。未转换交换可以作为机制反事实，但必须控制尺度，
不能把其退化全部归因于抽象的“模型特异性”。

## 从命题到实验结论的边界

主矩阵估计的是固定有限算法的风险差，不是直接估计Bayes最优条件期望。
R成功超越查询侧/随机/错配，支持该算法下的检索增量；R失败只说明当前
探针、记忆、模型和分布组合没有建立收益，不能证明历史完全无信息。
本轮固定随机特征在附加输入替换后不保证有限函数类严格嵌套；参数与
有效自由度相同控制拟合复杂度，但不能证明优化、表征完全等价。理论的
嵌套信息最优风险结论不可直接套到有限探针的点估计上。

不同基础模型的预训练数据和训练预算并不相同，因此“基础模型”作为
固定实验条件，不能将其差异解释为架构本身的单一因果效应。因果程序
对照针对每个固定模型内的记忆/配对/输入臂，跨模型用于检验边界可复现性。

跨模型只在部分组合有效是允许且有价值的结论。要声称有普适判据，还
必须通过留数据集、留模型及两者同时留出的验证，且不能以已查看TEST
挑阈值。不能从预测误差大推断系统具有混沌动力学，也不能从多轮调参
没有改善推断剩余误差全是不可约噪声。

检验“有效性依赖基础模型”时，直接比较配对交互
`I_mn=Delta_extra(m)-Delta_extra(n)`。一个模型显著而另一个不显著，并不能
证明I不为0。主矩阵同时保存相同查询、种子、时间块的效应，再对六个模型
对做独立的次要Holm检验族。它检验这些固定模型条件的差异，不把不同训练
预算与预训练来源混称为纯架构因果效应。

还必须区分“案例记忆有用”和“细粒度匹配必要”：R相对B1/N/P成立之后，
仍应比较十个固定均匀旧案例的全局记忆校准M。四个模型的R/M比较构成
独立次要Holm检验族。如果M与R相当，最多支持记忆或全局偏差辅助，不能
声称精细检索不可替代。该分析在新F评分前独立固定，不替换12个主检验。

## F评分前固定的统计补充：相关跨度与样本量

主区间不把通道或相邻窗口视为独立重复。除同步通道和配对种子外，块长
采用`7天 * ceil((512+96)/(7*每日点数))`，即小时数据28天、15分钟和10分钟
数据7天，至少覆盖一个完整查询窗口。该补充在F评分前保存于
`analysis_plan.json`，优先于初稿协议中的固定七天块描述，不改变预测、
训练或任何算法臂。仍须承认块长并不能保证真实独立或平稳。

单元少于8个时间块时标为证据不足；即使探索性p值较小，也不能包装为
该单元的稳健确认。正式外部研究应规划至少12个有效块；小时数据对应
至少约336天测试跨度，或采用预先固定、测试不重叠的多外层前推折。
增加同一时间的通道数不能代替延长独立时间覆盖。
