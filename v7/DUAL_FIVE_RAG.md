# 重排5个，加原始历史5个

当前实现保留96点历史、96点预测和原100候选重排选5机制，再增加一条只比较原始历史数值的检索路径。两个分支各提供5个案例。Moirai和已有未来状态编码器保持冻结，本轮不新增微调或重新拟合预测器。

## 两组案例怎么选

第一组沿用已冻结的五案例模型，包含其原召回方式、未来状态评分、0.8未来兼容与0.2历史相似的重排先验、案例库范围和验证确认的预测策略。额外的自训练未来原型评分也保留原配置，不在测试上调参。

第二组的唯一数值评分为`mean((query_raw_history - old_raw_history)^2)`，只比较原始96点历史。它不去趋势、不独立标准化窗口，不使用Moirai预测、未来编码或任何未来评分。因而原始水平、幅度和趋势都会影响选择。距离相同时按旧案例开始位置排序。排除与第一组完全相同的案例，再按距离顺序贪心选5个；第二组内部案例开始位置至少相差192点，避免5个邻近窗口其实来自同一段记录。

第二组使用与第一组当前分支相同的冻结库范围：原初始前缀，或者截至TRAIN结束的前缀。它不会额外扩大库以获得不公平优势。两组之间的完整旧区间可能交叠；去重和第二组内部192点间隔不能把十案例称为十个统计独立样本。

所有十个案例都必须满足`old_start + 192 <= min(query_history_start, frozen_library_end)`。这是完整历史加未来的边界，要求旧案例未来在当前查询历史开始前已经观测完，而不是只在当前预测开始前完成。自身、与查询重叠的192点区域和未完成案例不能被使用。病例的训练标签与推理时已知旧未来是不同用途。

## 选中后的数值怎么用

第二组“按历史数值选”，不等于把旧历史拼接进Moirai。Moirai输入仍然是当前原始96点历史。两组各自的已观测旧未来作为辅助预测信息，通过外部修正使用。

旧未来先按旧历史末16点水平及历史标准差映射到当前状态；尺度比限制在0.25至4之间。两组各5个等权聚合，不能让一组因评分大小吞掉另一组。原五案例预测保留它已有的权重、适配器和编码器贡献。

固定5+5增量迁移对照的计算方式是：

1. 用相同冻结编码器计算每个旧案例的历史预测，并从其实际旧未来减去这部分，得到对齐后的旧预测残差。
2. 分别计算重排组与原始历史组的平均旧预测残差，记为`m_rank`、`m_raw`。
3. 十案例相对于原五案例等权残差平均的变化为`d = 0.5*(m_raw - m_rank)`。两组各占一半；当前编码器路径在这一差分中抵消。
4. 用组内残差方差对`d`收缩：`d² / (d² + 0.25*(var_rank/5 + var_raw/5))`。第二组内部不交叠有助于减少重复记录，但该公式仍只是可靠性启发式，不是已校准的统计置信度。
5. 用原始历史支持度进一步收缩：`support = 1/(1 + median(raw_history_distance)/query_scale²)`，修正乘`sqrt(support)`。查询尺度使用当前历史标准差，最低为初始库标准差的0.1倍。
6. 限制增量绝对值，不超过Moirai90%与10%分位跨度的四分之一，也不超过当前历史尺度的两倍。
7. 最终输出`F5 + 0.25 * bounded_increment`。`F5`是既有已确认预测，因此新增案例不会直接替换已有效的预测状态。

这是基于十案例差异的增量专家，不是把原五案例的分数权重精确替换成十个等权权重。它保留原预测，并用同一编码器构造的等权五案例反事实作为增量参照。

## 对照和回退

另设固定直接十案例平均、十案例残差迁移、两组一致性收缩、旧修正信任收缩，以及不减旧编码器预测的数值差分对照。它们都在相同查询、同一Moirai输出和同一编码器上比较。数值差分和残差差分使用旧预测作为基础；其余直接路径使用Moirai中位数。固定专家统一使用0.25修正强度；信任收缩是固定完整收缩，不另乘0.25。

验证策略先按每个变量的时间顺序分三个块。前两块选择一次专家及强度，每块都要求MSE至少改善1%、至少75%查询改善且MAE下降。第三块只能确认或者拒绝这一选定组合，不能寻找第二个组合。确认失败时保留既有预测。

因此必须区分：固定5+5对照每个查询都利用十案例；验证保护版本虽然检索十案例，拒绝时只使用旧预测，而旧预测本身可能只用五案例或不使用检索。`query_dual_five.py`分别返回`retrieved_cases`和`used_cases`，以及两组的实际开始位置。不能把大量回退后接近旧结果当作十案例显著有效。

无检索对照沿用相同容量的已训练编码器，不给新版本增加预测模型训练容量。所有原始MSE、MAE和初始库尺度归一化NMSE都保留，不能因归一化指标改善而隐藏大幅度变量的原始误差退化。

## 复现与限制

```powershell
.venv-moirai/Scripts/python.exe -m v7.benchmark_dual_five --source v7/runs/case_transport_fixed_96_20261014 --output v7/runs/dual_five_distinct_96_20261014 --datasets ETTh1 ETTh2 ETTm1 ETTm2 weather electricity traffic
.venv-moirai/Scripts/python.exe -m v7.verify_dual_five --root v7/runs/dual_five_distinct_96_20261014 --datasets ETTh1 ETTh2 ETTm1 ETTm2 weather electricity traffic
.venv-moirai-gpu/Scripts/python.exe -m v7.verify_dual_five --root v7/runs/dual_five_distinct_96_20261014 --datasets ETTh1 ETTh2 ETTm1 ETTm2 weather electricity traffic --live
```

`dual_five_rag.py`提供检索与融合；`benchmark_dual_five.py`先保存验证策略再读取测试；`query_dual_five.py`接受真实历史预测；`verify_dual_five.py`重建评分、边界、目标、策略、预测和指标，并检查实际接口。输出目录必须不存在，避免覆盖已冻结实验。

实验复用已探索时期和抽样窗口，不是官方全量划分，也不是新盲测。曾有不限制新增案例间隔的初步对照，仅作为开发探索保留。再次验证不能消除多轮探索偏差。原始数值距离的绝对水平匹配也会丢掉有用的跨水平形状相似案例，历史相似仍不能保证未来相似。

Illness的既有初始前缀只有50个完整192点案例，不能套用原100候选与独立验证协议；本轮不伪造相同条件的分数。
