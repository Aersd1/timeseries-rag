# V6：未来概率引导的时间序列检索

目标：检索到**对未来预测有帮助**的历史片段，而不仅是过去形状相似的片段。

这是一套可在服务器训练、建库、评估的研究实现。本轮已用服务器现有权重做真实数据推理对照，并优化了索引和训练代码；本地没有正式训练新网络，没有证明 10B 规模或任意条件下每次低于 100ms。

**当前主方案：[同时约束历史与未来的联合检索](JOINT_RETRIEVAL.md)。** 包含真实历史距离门槛、联合训练目标、历史近邻批次和配对实测。纯 learned 的加速及融合对照见 [本轮优化报告](OPTIMIZATION.md)。旧 checkpoint 兼容；新 CDF 编码与训练约束需要重训编码器。

## 模型与检索流程

```mermaid
flowchart LR
  X[可见历史 X] --> P[概率网络]
  P --> B[未来各模式的概率、均值、标准差]
  X --> E[历史编码器]
  B --> E
  E --> V[32 维检索向量]
  V --> I[长段分片 → 多层包围盒 → 叶块向量]
  I --> N[排除自身和重叠窗口]
  N --> A[读取历史候选的后续片段]
  A --> F[加权类比预测]
```

**训练**允许使用训练样本的真实未来作为监督。**查询**只输入过去的 244 点；概率网络推断未来分布，不读取查询的真实未来。数据库候选的后续片段来自已经发生的历史。

### 1. 条件贝叶斯网络

图结构是 `X → Z`、`(X,Z) → Y`：

\[
p(Y,Z\mid X)=p(Z\mid X)\prod_{t=1}^{H}p(Y_t\mid X,Z).
\]

- `Z` 为共享的离散未来模式，默认 4 类。
- 神经网络根据历史输出模式概率和每个模式的未来均值、标准差。
- 每个模式内部使用对角高斯；通过共同的 Z 表达部分跨时间相关性。
- 用混合分布负对数似然训练，支持多种可能的未来，而非仅一个均值。
- `posterior()` 可按贝叶斯公式计算 `p(Z|X,Y)`，仅用于训练/诊断；查询不用它。

这里是**神经网络参数化的概率有向图**，神经网络权重使用点估计；不是权重后验意义上的 Bayesian Neural Network。它描述条件随机性，未建模完整的参数不确定性，也不是完整动态贝叶斯网络。

### 2. 概率引导编码器

先在 memory 区间训练概率网络，再冻结；在后续 train 区间训练编码器：

1. 卷积网络编码历史。
2. 新配置合并未来 CDF、均值和方差摘要，不受混合模式编号交换影响；旧 checkpoint 保留原来的模式拼接。
3. 生成归一化的 32 维向量。
4. 使用真实未来与概率分布的批内软对比损失、未来预测和概率特征重建损失；新配置另外约束表示方差与协方差。

未来相似度同时考虑 H=24、96、244。训练对比排除自身，以及同序列历史+未来区间相互重叠的样本。`use_belief=false` 可做没有概率输入和概率重建损失的对照，仍保留未来监督。

### 3. V4 思路的多层检索

保留 V4 的“长段→较小块→精确距离→位置”结构，但**重新计算学习向量的下界**，不复用针对原始序列距离的 SFA/PAA 下界。

- memory 中每个合法起点默认都有编码，`stride=1`；默认只入库能容纳全部未来 H 的起点。
- 每个分片覆盖连续时间起点；新配置在分片内按向量几何重排，再以每 256 个向量一个叶块、16 叉合并包围盒，另存真实起点映射。
- 用查询到包围盒的欧氏距离下界决定访问顺序。
- 在叶块中计算真实 float32 存储向量的距离；使用 float64 运算与保守边界裕量。
- 初次就保留冗余候选，只维护容量 M 的候选缓冲区；批量选择，不缓存全库所有距离、不因候选不足反复扫描。
- 对候选按距离排序后，贪心排除同一逻辑序列重叠窗口。244 点窗口起点至少相隔 244。

默认 `M = k × 512`。整数起点下，一个选中窗口最多排除 `2L-1` 个起点；因此默认 L=244 时冗余足够保守。减少冗余可提速，但可能返回不足 k 个，结果明确报告 `complete_topk=false`。不自动扩大候选再查。

`leaf_budget=0, time_budget_ms=0` 是完整搜索；提前耗尽预算的搜索会返回 `certified=false`。`exact_diverse_topk=true` 只表示在**当前入库窗口、查询范围、排除规则与编码距离**下得到完整的贪心非重叠 Top-k，不代表真实未来最近邻。

## 时间与空间复杂度

设 N 为已入库窗口数，d 为向量维度，B 为叶块数，V 为查询访问的节点数，C 为精确评分窗口数，M 为候选堆容量，k 为返回数量。

- 编码：固定历史长度下是固定模型推理成本 `T_encode`。
- 检索：几何下界与精评分约 `O(V·d + V log B + C·d)`；当前批量候选维护还需每叶 `O(M+leaf_size)`，等距排序及最终排序另计。完整公式见优化报告，再加候选未来读取 `O(k·(L+H))`。
- 最坏情况不能有效剪枝，C=N、V=O(B)，仍是线性扫描量级；没有 `O(log N)` 保证。
- 预算模式限制访问的叶块数，不严格限制内部节点、磁盘缺页或模型时间；时间预算是软预算，不保证端到端 100ms。
- 向量磁盘空间 `4Nd` bytes，时间布局起点 `8N` bytes；空间布局每通道再加 `8N` 的位置映射。边界约 `8d·N/leaf_size·fanout/(fanout-1)` bytes。
- 查询只保存 M 个候选距离和一个叶块的临时距离；节点优先队列最坏 O(B)，模型/目录/映射页另计。
- 建库必须对每个合法窗口编码，成本 `O(N·T_encode)`；当前没有可增量复用的全卷积编码或分布式建库。

100 亿可用起点、stride=1、32 维 learned-only 空间布局时，向量约 **1.28 TB**，两个起点数组约 **160 GB**，另有边界和原始值。这是尺寸估算，不是已完成的 10B 测试。默认实验另存 history/belief 对照，因此更大。`python -m v6 estimate --config v6/configs/server.json --points 10000000000` 可估算。

## 什么结果才算成功

应同时看到：

1. 测试集上 learned 检索的预测误差低于 history 检索、最后值预测和无概率输入消融；配对置信区间支持收益。
2. 未来概率分布覆盖率接近标称水平，区间宽度合理。
3. 预算检索相对完整编码搜索保持较高召回，同时 p95/p99 与最大延迟可接受。
4. 多随机种子、不同数据集下仍成立。

即使都成立，也不能保证每次查询的未来都相似。不可预测噪声、状态突变和分布变化会限制这一目标。
